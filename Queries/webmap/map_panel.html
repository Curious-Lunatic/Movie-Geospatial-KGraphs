Data, methods & QGIS

Nearby and heritage searches use geographic distance buffers. Drawn areas and travel-time contours select points inside polygons. Region searches overlay movie locations with published state and district boundaries. Route searches buffer an actual road route; corridor width measures distance from the route, not driving detour distance.

Travel-time polygons are modelled reachable areas, not guaranteed arrival times. Routing uses the public Valhalla / FOSSGIS service with OpenStreetMap data, subject to availability and rate limits. No straight-line fallback is presented as a road result.

Boundary preparation uses Shapely geometry repair, simplification, polygon overlap and point-in-polygon joins. QGIS can open the exported analysis and source layers for independent inspection; a running QGIS server is not required.

Boundaries: geoBoundaries, state source CC BY 2.5 IN; district source Pathways Data / Local Government Directory, ODbL 1.0. Source metadata reports 2011 / 2021; these research layers may differ from current boundaries. A nearby movie is not evidence of filming at the selected heritage site.
